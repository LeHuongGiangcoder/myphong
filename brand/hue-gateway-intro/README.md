# Hue Gateway Animation Kit

Start with **ANIMATION-GUIDE-VI.md**. Copy **VIBE-CODING-PROMPT.txt** into your coding tool together with the entire assets folder and manifest.json.

Preview: open **demo.html**, or run `python -m http.server 8000` from this directory and visit `http://localhost:8000/demo.html`.

- `assets/`: registered alpha PNG layers, optimized start/end WebP, crop helpers, rough SVG mask path.
- `manifest.json`: exact placement and timings.
- `layer-contact-sheet.jpg`: visual inventory.
- `demo.html`: dependency-free Canvas 2D motion reference with Open, replay, reset and timeline scrubber.

Master size 1080 × 1920, normalized from 941 × 1672 inputs. This is a practical 2.5D reconstruction, not native editable painting layers or a physically correct 3D door rig. Fog was reconstructed separately with imagegen; exact source pixels are preserved for the clipped architecture and door layers.
